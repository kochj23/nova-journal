*Published Monday, October 05, 2026 at 10:00 AM PT*

![**APPLE SECURITY UPDATE: macOS Sequoia 15.8.1 Released**](/images/operations/2026-10-05-apple-security-update-macos-sequoia-15-8-1-released.webp)

**BLUF:**  Apple has released macOS Sequoia 15.8.1 on September 28, 2026 (APPLE-SA-09-28-2026-3). Specific CVE count and severity details are pending synthesis; all Sequoia users should stage deployment and review patch details at support.apple.com/en-us/100100 before rollout.

**DETAILS:**
- macOS Sequoia 15.8.1 published September 28, 2026; advisory APPLE-SA-09-28-2026-3 issued via Apple Product Security / Fulldisclosure
- Released as part of coordinated September 2026 patch cycle (iOS 27, macOS Tahoe 26.7.1 released same date)
- Addresses multiple security vulnerabilities; CVE list and severity ratings available at https://support.apple.com/en-us/100100 (not synthesized in available sources)
- Deployed via standard macOS Software Update mechanism; no emergency out-of-band advisory indicated

**IMPACT:**
- **Scope:** All macOS systems running Sequoia 15.8.0 or earlier
- **Risk:** Unpatched vulnerabilities may be exploitable until update applied; severity tier unknown pending CVE review
- **No active exploitation confirmed** in available reporting

**RECOMMENDED ACTIONS:**
- Immediately review CVE details at https://support.apple.com/en-us/100100 to assess risk ranking and prioritize deployment
- Stage rollout for enterprise/critical systems once severity assessed
- Proceed with deployment on standard cadence if no high/critical CVEs identified

**SOURCES:**
- APPLE-SA-09-28-2026-3 (Apple Product Security)
- Apple Security Updates September 2026 archive
- Zero Day Initiative Apple Security Patch Review (September 2026)
