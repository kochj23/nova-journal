*Published Sunday, November 15, 2026 at 10:02 AM PT*

Apple has released macOS Golden Gate 27.2.1, a security update for Mac users. Affected users should install it, but the specific vulnerabilities it fixes could not be confirmed from available sources.

**DETAILS**
- Apple's security advisory for the release is listed as APPLE-SA-11-09-2026-4, "macOS Golden Gate 27.2.1." Apple Product Security posted it to Fulldisclosure on November 12, 2026.
- Apple's official CVE list is at support.apple.com/en-us/100100. This alert did not have access to that page's contents, so the number of CVEs and their details are **unconfirmed**.
- The release follows macOS Golden Gate 27.2, which Apple published under APPLE-SA-10-26-2026-4 on October 27, 2026.
- Whether 27.2.1 addresses any vulnerabilities that are known to be actively exploited has not been confirmed.

**IMPACT**
- Affected: Mac users running macOS Golden Gate 27.x. Exact affected versions are unconfirmed beyond the update's own release notes.
- Scope and severity: unknown until the CVE list is reviewed. Do not assume a severity rating from this alert.

**RECOMMENDED ACTIONS**
- Install macOS Golden Gate 27.2.1 through System Settings > General > Software Update. Apple's security updates are generally recommended for all users.
- Review the CVE list at support.apple.com/en-us/100100 to determine severity and whether any fixes apply to your environment.
- For managed fleets, confirm the update is deployed and track compliance through your MDM.
- This alert will be updated when CVE details are confirmed.

**SOURCES**
- Apple Product Security advisory APPLE-SA-11-09-2026-4, via Fulldisclosure (seclists.org), November 12, 2026
- Apple Support security page: support.apple.com/en-us/100100 (contents not reviewed for this alert)
